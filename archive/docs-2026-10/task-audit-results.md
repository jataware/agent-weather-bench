# Task and evaluator audit — 5 October 2026

The repository now has four runnable development task packages. This audit collected three fresh inexpensive attempts for each existing task, then one Astra and two Claude Fable 5.1 attempts on a new short-rains workflow. Original submissions, tool traces and earlier assessments remain intact. No scientific hints or grader feedback were supplied to the solvers. An earlier adapter-failure trial is recorded separately from the twelve task attempts.

The new task is substantial, but these observations do **not** establish a frontier scientific ceiling. Astra completed its numerical and execution requirements; a larger-output Fable run matched the scientific calculations but stopped before delivering all workflow metadata. These are useful capability, framework and cost observations, not proof that the underlying methods are beyond either model.

The short-rains task repairs an authentic monthly-unit convention, uses September issue-time information, searches 108 candidates inside rolling training folds, implements Student-t predictive uncertainty, and retains one fitted state for independent retrospective targets. Two independent implementations agree within 4e-15 in probabilities. A known-correct executable passes all offline probes. Constructed target leakage and cached inference match original arrays but fail their respective perturbation checks. The correct reference finds that nested search loses to the fixed forecast-IOD predictor in all three regions; negative findings can receive full credit.

## Calibration improvements and remaining limits

The audit fixed two classes of false rejection: valid float32 disagreement arithmetic, and equivalent enumerated/endpoints JSON year periods where the task prescribed a period without prescribing notation. Independent tests reject real units, grid, missingness, arithmetic and period defects. The scientific references and original model outputs were unchanged.

Judge packets now include bounded scientific tool traces, with explicit omissions and without provider responses, costs or authentication metadata. Neil Hausmann’s substrate summary continues to distinguish observable listing, reading and execution; it does not establish unobserved understanding. Missing controller infrastructure leaves execution unresolved, while failed scientific commands or malformed outputs fail their own checks. The run report exposes criterion outcomes alongside score bounds. Future runs retain their launch lock separately from any later assessment policy; earlier pilot launches do not all have that newer record.

There are **138 passing tests**, including independent numerical contrasts, acquisition boundaries, provider budget accounting, trace redaction/omissions and temporal/inference checks. Four package data manifests validate, and references recompute. These checks establish specific behavior; they do not establish perfect expert judging.

Seven blinded real/constructed judge packets and operational expectations are prepared. **No paid judge calls were made.** Automatic approval review rejected exporting those scientific artifacts and tool-trace excerpts to Anthropic without explicit destination permission; the user question is pending. Human labels remain unset, and task scientific/scoring/redistribution approvals remain false. Neither passing replay nor a proposed local review is human scientific sign-off.

The next scientific difficulty increase should stay within this forecasting family. A concrete candidate is multivariate calibration parity and causal adaptation: reproduce a documented CCA/eREG case, distinguish deterministic cross-validation from full-fit probabilistic validation, then adapt training-only spatial transforms and nested mode selection to September-issue forecasts. The existing SST and rainfall matrices suffice. Public algorithm semantics and independent parity fixtures must be verified before packaging; this variant is proposed, not implemented. It adds consequential method choices rather than unrelated task families or obscure file formats. The current audit has not yet established a task at the frontier ceiling or independently calibrated expert-judge accuracy.
