# Agent Weather Bench documentation

Start with [the roadmap](roadmap.md). It summarises the system, what remains to build and the experiments to run, in three pages.

- [The results so far](results.md) give the outcomes of the first 36 attempts, the judge's record, and a diagram of how one run works.
- [The task set](task-set.md) lists the 25 task templates, their modes and levels, and what each exists to compare.
- [The assessment format](assessment-format.md) defines the submission envelope, the three modes, the check types, the judge, certification, and what was measured on the first attempts.
- [Task templates](../templates/README.md) explains the `assessment/` package: the template folder layout, the commands, tolerances and certification.
- [The WMO objective seasonal forecasting checklist](../standards/wmo-objective-seasonal-forecasting/README.md) is the first standard for process-mode templates. It is a draft.
- [Running the first harness](harness.md) covers the ten packaged tasks still assessed by the first evaluator: systems, adapters, run storage, retained and reset sequences, and the locked judge.
- [Task authoring for the first evaluator](task-authoring.md) gives the package layout and registration points for those tasks.
- [Internal setup](internal-setup.md) explains checkout checks, the separately shared task data, Docker builds, and pending review and licence work.
- [Task critiques of 2 October 2026](reviews/2026-10-02/response.md) are kept here because the packaged tasks link to them.

Superseded documents, the calibration studies of the first evaluator and their scripts are under [`archive/docs-2026-10/`](../archive/docs-2026-10/README.md). The completed pilot is under [`archive/pilot-2026-10-01/`](../archive/README.md).
